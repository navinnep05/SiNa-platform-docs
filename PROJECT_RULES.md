# Project Rules

## Purpose

Define the operating rules for the shared Driver Booking platform docs repository.

## Core Rules

- Always read `AGENTS.md` before making changes.
- Keep governance, standards, roles, skills, decisions, execution logs, and roadmap material in this repository.
- Treat this repository as the source of truth for cross-repo standards and architectural guidance.
- Keep shared guidance consistent with backend and mobile repository-local `AGENTS.md` files.
- Update documentation when behavior, structure, or contracts change.
- Prefer controlled duplication only when a concise repo-local pointer is required.
- Do not push any repository changes until the user explicitly says to push.

## Scope

- Applies to all docs, governance, and shared guidance artifacts for the Driver Booking platform.
