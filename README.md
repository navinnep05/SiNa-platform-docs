# Driver Booking Platform Docs

Source of truth for shared governance, architecture notes, standards, roles, skills, prompts, decisions, execution logs, and roadmap material for the Driver Booking platform.

## Repository Contents

- `AGENTS.md` - operating instructions for contributors and agents
- `PROJECT_RULES.md` - repository-level governance rules
- `docs/` - architecture and delivery documentation
- `standards/` - coding, API, git, naming, logging, exception, and review standards
- `roles/` - role-specific guidance
- `skills/` - reusable technical skill notes
- `prompts/` - reusable prompt templates
- `decisions/` - architecture decision records
- `execution-log/` - progress and execution tracking
- `roadmap/` - roadmap and planning artifacts

## Usage

Read `AGENTS.md` and `PROJECT_RULES.md` before making changes in any of the sibling repositories.
