# Driver Booking Platform Docs

Source of truth for shared governance, architecture notes, standards, roles, skills, decisions, execution logs, and roadmap material for the Driver Booking platform.

## Repository Contents

- `AGENTS.md` - operating instructions for contributors and agents
- `PROJECT_RULES.md` - repository-level governance rules
- `docs/` - organized documentation ([index](./docs/README.md))
  - `product/` - PRD, flows, readiness
  - `architecture/` - system design, stack, security, data
  - `design/` - UI guidelines
  - `delivery/` - testing, deployment, phase implementation status
  - `api/` - OpenAPI contract
- `standards/` - coding, API, git, naming, logging, exception, and review standards
- `roles/` - role-specific guidance
- `skills/` - reusable technical skill notes ([skills index](./skills/README.md))
- `decisions/` - architecture decision records
- `execution-log/` - progress and execution tracking
- `roadmap/` - roadmap and planning artifacts

## Usage

Read `AGENTS.md` and `PROJECT_RULES.md` before making changes in any of the sibling repositories.
