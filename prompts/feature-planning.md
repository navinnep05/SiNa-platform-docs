# Feature Planning Prompt

Use this prompt when planning a platform feature that will touch backend, mobile, or both.

## Inputs

- Feature name
- Business goal
- Repositories affected
- UX or API dependencies
- Unknowns

## Prompt Template

Plan the following Driver Booking platform feature with a production-ready implementation sequence.

Context:
- <paste context here>

Return:
- A high-level implementation sequence
- Cross-repo dependencies
- Documentation and governance updates
- Risks and assumptions
