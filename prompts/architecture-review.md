# Architecture Review Prompt

Use this prompt when reviewing an architecture decision, repository structure, or cross-repo change.

## Inputs

- Goal
- Constraints
- Repositories affected
- Risks
- Open decisions

## Prompt Template

Review the following Driver Booking platform change for architectural fit, risks, and missing governance updates.

Context:
- <paste context here>

Focus on:
- Clean Architecture alignment
- Repository boundaries
- Documentation updates
- Rollout risks

Return:
- Findings ordered by severity
- Recommendations
- Any missing documentation artifacts
