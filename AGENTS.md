# AGENTS.md

This repository is the source of truth for Driver Booking platform governance.

## Operating Instructions

- Always read `PROJECT_RULES.md` before making changes.
- Follow every applicable document in `standards/`.
- Keep architecture, decisions, execution logs, and roadmap updates here.
- Avoid duplicating governance content into backend or mobile repositories.
- Update documentation whenever the platform structure or contracts change.

## Scope

- Applies to `docs/`, `standards/`, `roles/`, `skills/`, `prompts/`, `decisions/`, `execution-log/`, and `roadmap/`.
